Renders a Lucide line icon (2px stroke, 16px default) as inline SVG; use it everywhere an icon sits next to text.

```jsx
<Icon name="calendar" />
<Icon name="circle-check" size={20} color="var(--status-ok-fg)" />
```

Needs `<script src="https://unpkg.com/lucide@0.460.0/dist/umd/lucide.min.js"></script>` before the bundle. Icons are never used alone to carry meaning: pair them with a word.
